# DS4Windows 4.6.7 한국어 확장 빌드

이 저장소는 hbashton/DS4Windows 4.6.7에 한국어 번역을 추가하고,
영어로 고정되어 있던 화면 문구를 번역 리소스에 연결하는 **비공식 수정본**을 빌드합니다.

사용자 PC에 .NET SDK나 Visual Studio를 설치하지 않습니다.
빌드와 자동 검사는 GitHub의 표준 Windows 서버에서 실행합니다.
개인 프로필·사용자 설정·설치 백업·로그·인증 정보는 이 저장소에 포함하지 않습니다.

## 현재 준비 상태

- 기준 소스: `hbashton/DS4Windows`의 `VIIPERRC4.6.7`.
- 고정 커밋: `080495de61ae8b6ada6b4252337838e8b22119b8`.
- 기본 한국어 문자열 619개에 화면 번역 연결을 추가했습니다.
- 적용 결과: 한국어 리소스 항목 1,314개, 화면 속성 965곳을 번역 리소스에 연결합니다.
- 개요, 프로필, 설정, 오디오 햅틱, 트리거 연구소, 프로필 편집기와 보조 화면이 포함됩니다.
- 언어 선택 후 설정 저장 호출도 복구합니다.
- 컨트롤러 프로토콜, 입력 매핑 로직, 드라이버 코드는 변경하지 않습니다.
- 동적으로 생성하는 일부 진단·장치 상태·선택 항목 및 타사 화면에는 영문이 남을 수 있습니다.
- **로컬 정적 검사는 통과했으며, 실제 Windows 컴파일과 물리 컨트롤러 검증은 아직 별도 단계입니다.**

## 빌드 실행 방법

1. 이 저장소의 **Actions** 탭을 엽니다.
2. 왼쪽에서 **Build DS4Windows 4.6.7 Korean**을 선택합니다.
3. **Run workflow**를 누르고 `main`을 선택한 뒤 실행합니다.
4. 성공하면 실행 내역 하단 **Artifacts**에서 **DS4Windows-4.6.7-Korean-x64**를 받습니다.
5. 다운로드한 압축 파일 안의 `DS4Windows_VIIPERRC4.6.7-ko.2_x64.zip`이 실행용 패키지입니다.

`main`의 일반 빌드는 버튼으로 실행할 때만 시작합니다.
실패 원인 수정용 `fix/korean-ui-threading` 분기만 변경 시 자동으로 검증합니다.
이 분기의 검증은 수정본 검사와 수정하지 않은 원본 검사를 각각 실행해 비교합니다.
공개 저장소에서만 빌드 작업을 실행하도록 제한했습니다. 비공개 저장소에서는 작업을 건너뜁니다.
일반 `windows-2022` 서버를 사용하며 유료 대형 서버는 사용하지 않습니다.
공개 저장소의 표준 서버 컴퓨팅은 GitHub 공식 정책상 무료입니다.
결과 파일은 누적을 줄이기 위해 1일 후 만료됩니다. 성공하면 바로 저장하세요.

공식 요금 설명: https://docs.github.com/en/billing/concepts/product-billing/github-actions

## 실행되는 검사

1. 정확한 upstream 커밋인지 확인하고, 깨끗한 소스에 번역을 적용합니다.
2. 번역 키·서식 인수·XML 구조를 확인합니다.
3. 화면의 배치 구조, 컨트롤 이름, 이벤트 연결, Tag, 기존 바인딩이 유지되는지 원본과 비교합니다.
4. 표시 문구를 제외한 C# 코드가 원본과 같고 기존 테스트의 검증문이 유지되는지 검사합니다.
5. 원본 프로젝트 테스트와 `ko`/`ko-KR` 전체 한국어 리소스 검사를 실행합니다.
6. x64 독립 실행 패키지를 빌드합니다.
7. 실제 배포용 `Lang` 폴더 구성에서 리소스를 읽어 확인합니다.
8. 모든 단계가 성공한 경우에만 실행용 ZIP을 제공합니다.

리소스 확인 프로세스는 앱 진입점과 컨트롤러 서비스를 실행하지 않습니다.
자동 검사는 실제 게임 입력·햅틱·Bluetooth 연결·화면 잘림 검증을 대신하지 않습니다.

첫 시도에서는 컴파일 후 7,183개 검사가 통과하고 16개 UI 검사가 실패했습니다.
독립된 로그 화면 검사에서 번역 네임스페이스가 소실됐고, 추가된 번역 참조가
독립 STA 화면 생성과 공용 디스패처의 수명 문제에 노출됐습니다.
수정본은 새 문구를 현재 언어의 ResourceManager에서 직접 읽는 표시 전용 확장을 사용합니다.
기존의 재시작 후 언어 적용 방식은 유지하며, 원본 UI 검사와 별도 스레드 회귀 검사로 확인합니다.

## 다운로드 후 적용

이 빌드는 아직 집 PC의 설치본에 적용된 것이 아닙니다.
기존 DS4Windows와 설정을 백업하고 종료한 상태에서 별도 폴더로 먼저 실행·검증해야 합니다.
`AppData`의 기존 프로필을 읽을 수 있으므로, 컨트롤러와 프로필의 실제 동작을 확인한 뒤 설치본 교체를 판단합니다.
공식 업데이트를 설치하면 본체 한글화 수정이 덮어써질 수 있습니다.

## 저장소 구성

- `apply_korean.py`: 소스에 번역 연결 및 언어 저장 수정을 적용합니다.
- `validate_korean.py`: 원본과 비교하여 표시 문구 외 변경을 검사합니다.
- `data/ui-ko.json`: 추가 UI 번역과 기존 번역 목록입니다.
- `data/Strings.ko.resx`, `data/Resources.ko.resx`: 기본 한국어 리소스입니다.
- `support/`: 리소스 검사 및 기존 레이아웃 검사를 유지하기 위한 보조 소스입니다.
- `.github/workflows/build-korean.yml`: 수동 실행 전용 Windows 빌드 구성입니다.

빌드 결과에는 기준 소스와 이 저장소의 커밋 ID, SHA-256, 검사 보고서를 포함합니다.
이 저장소의 수정 스크립트·번역·보조 소스와 아래 고정 원본으로 수정본을 재생성할 수 있습니다.
